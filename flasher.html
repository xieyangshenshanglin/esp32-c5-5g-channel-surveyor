?打不开 / 烧不进 怎么办

    

      
现象原因与处理

      
        
双击后是纯文本 / 代码右键 → 打开方式 → Chrome 或 Edge。别用 IE、别用记事本。

        
点连接没有任何弹窗页面被嵌在别的窗口/iframe 里了。把本文件单独用浏览器打开（地址栏应是 file:///…）。

        
列表里没有你的板子线只充电不能传数据 / 驱动没装（CH340、CH343 装 CH341SER）/ 换个 USB 口。

        
打开串口失败：拒绝访问被别的程序占着：串口助手（sscom、XCOM）、Arduino 串口监视器、另一个浏览器标签页。全关掉再点连接。

        
卡在 SYNC 握手失败① 勾着"自动进下载模式"就点连接，别手按 BOOT；② 手按 BOOT → 点一下 RST → 松开 BOOT 再重试；③ TX/RX 两根都要接（只接 TX 能看日志，握不上手）；④ 降到 115200。

        
写到一半报校验和错误线太长/杜邦线接触不良，或这个波特率它撑不住 → 降到 460800 或 115200 重试。

        
烧完还是老程序烧错文件了。核对「大小」与文件：整片镜像约 1.1 MB，Bruce 那种约 3.9 MB，别混。

        
烧完没反应 / 要重插拔插一次 USB，或按一下 RST。原生 USB 口（303A）复位后会重新枚举。

      
    

    
本页不联网、不上传任何东西：固件只在你电脑的内存里，通过串口直接写进芯片。
